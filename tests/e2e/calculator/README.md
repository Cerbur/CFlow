# Calculator

A minimal TypeScript calculator used as the deterministic fixture of the
CFlow Gate 1 end-to-end demo.

## Operations

- `add(a, b)` — returns `a + b`.
- `subtract(a, b)` — returns `a - b`.

## Running the tests

```sh
npm test
```

The tests run through Node's built-in test runner (`node --test`); the
fixture has no npm dependencies.
